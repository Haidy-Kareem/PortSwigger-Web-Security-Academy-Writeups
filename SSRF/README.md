# SSRF (Server-Side Request Forgery)

This folder contains write-ups for SSRF labs from PortSwigger Web Security 
Academy, covering basic exploitation and filter bypass techniques.

## Covered Concepts
- Basic SSRF against local server
- Basic SSRF against back-end systems
- Blacklist-based input filter bypass
- Whitelist-based input filter bypass
- Filter bypass via open redirection
